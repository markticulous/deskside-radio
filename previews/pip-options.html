Always on top

The radio gets buried the moment you click anything else. Document Picture-in-Picture gives a web page a real operating-system window that floats above everything — on Windows, macOS and Linux alike. It is Chromium-only: Chrome and Edge have it, Firefox does not.

Two questions to settle here. First, whether the API works at all from a file:// page inside an app-mode window. Second, what should live in that little window.

Can this browser do it?
