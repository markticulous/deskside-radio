## Install it, or update it, with one file

### 🖥️ Windows

**Download `Win-Install-or-Update-Deskside-Radio.cmd` below and double-click it.**

That's all — it fetches this release, unpacks it beside the browser profile the radio already uses, puts a shortcut on your Desktop and opens it. Windows asks once whether to run a downloaded file; after that there are no prompts, on this run or on any update.

**Already have it?** Run **Deskside Radio - Update** from the Start menu, or double-click that same file in your app folder.

### 🍎 macOS and 🐧 Linux

The above installer is a Windows script, so it is no use to you — but **the radio itself runs perfectly well on both.** Take **`deskside-radio.zip`** instead, unzip it wherever you like, and open `index.html`. On Linux there is a `Linux - Create Desktop Shortcut.sh` inside for a proper launcher; on a Mac the radio makes its own shortcut from the button in its top bar.
