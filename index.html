Deskside Radio    v1.5.2

Browsers need one click before audio can play, so opening the page the ordinary way gets the usual tap panel, already tuned to this station. Run Win - Create Desktop Shortcut (Chrome).cmd once and the shortcut it makes opens the radio in a window that starts on its own.

Pick a city, then search by name or frequency.

    Listings come from radio-browser.info; the city lookup uses open-meteo. Direct MP3 and AAC streams play here. Entries flagged as HLS can still be added, but may not play.

    A slot plays one station between two times, handing over at its end. Slots never overlap: stretch one across another and the other is trimmed to fit, with an Undo. Give a slot the same time at both ends and it runs all day. A slot that runs past midnight belongs to the day it starts on. Between slots the radio keeps playing whatever is on, unless you set it below to switch off instead.

    Applies to any stretch with nothing scheduled — a gap between two slots as much as the end of the day. The radio comes back on by itself when the next slot starts. Set for weekdays and the weekend separately, so the weekdays can end at bedtime while the weekend carries on.

    Scrolling names

    Windows is set to reduce animation, so a station name longer than its box is cut off rather than scrolled. Nothing else in the app animates either, which is what that setting is for — but a name you cannot read is information lost, not motion saved.

    Backup

    A settings file holds the stations, the schedule, the theme and the sound settings. Nothing else leaves this machine. It is saved beside index.html, and every shortcut — Chrome, Edge, Firefox — reads it when it next opens: each browser keeps its own storage, and this file is the only thing all of them can see. So exporting is how settings move between them, and the most recent export is the one they all take.

    Desktop shortcut

    Opens the radio in its own window, tuned and playing, with no browser furniture around it — and on Windows it is also what keeps the app up to date, because the shortcut runs a small script that does the checking.

    Updates

    The app asks GitHub whether a newer version has been published when it opens, and every six hours it is left running, and shows a small Update available mark beside the wordmark when there is one. It sends nothing but the request. The page itself installs nothing and cannot — it is opened from a disk, and a page opened from a disk has no way to run a program.

    There is nothing to do. The shortcut you open the radio with runs a small script first, and once a day that script asks the same question the app does. If the answer is yes it fetches the new version in the background while you listen, and the radio is running it the next time you open it — which is when the readout says which version that is.

    Nothing is installed to do that — no service, no scheduled task, nothing in the registry, and nothing running when the radio is not. To take an update the moment you hear about it instead of waiting, run Deskside Radio - Update from the Start menu, or Win-Install-or-Update-Deskside-Radio.cmd in your app folder — hold Shift on this tab for a button that opens it. Either way it names the version it is putting down, and the one it is replacing, before it writes anything. To stop the radio updating itself, run Win - Automatic Updates.cmd with off in the same folder; with no argument it starts again.

    To take an update, follow the get it from GitHub link beside the notice, download deskside-radio.zip and unpack it over your app folder.

    Either way every station and setting survives, because those live in the browser profile rather than in the app folder.

    Reset

    Puts everything back to a fresh install: the three original stations, an empty schedule, no remembered city, and the sound settings at their middle.

    Filled in as Web stream

    A station with no frequency is almost always an internet-only one, which genuinely has no dial position — so rather than stopping to ask, that is what has been entered. If it does broadcast over the air, put the frequency in as 99.1 FM or 1010 AM and the dial will point at it.

    Shortcut downloaded

    Drag Deskside Radio.fileloc out of your Downloads to the Desktop. Double-clicking it opens the radio.

    Earlier versions wrote this as a .webloc, which Finder refuses for a file on your own disk — “the document content is not readable or is in the wrong format”. If one of those is on your Desktop, throw it away and make this one instead.

    1. If Finder still will not open it, drag the address itself out of your browser's address bar onto the Desktop. Safari and Chrome both make a working shortcut that way.
    2. To have it play on its own, turn on Play on launch in Settings and pick a station. Safari asks for one click before any page may play sound; Chrome on macOS will start by itself.

    Shortcut downloaded

    A browser cannot save a shortcut under its own name, so yours arrived as Deskside Radio.download and needs finishing. There is a quicker way.

    1. Quicker — run the helper. Double-click Win - Create Desktop Shortcut.cmd in the app folder, or paste this: It puts the shortcut on the Desktop, named and with its icon, and no warning. Then delete the download.
    2. Or finish this one. Rename it to Deskside Radio.url, drag it to the Desktop, then right-click → Properties → tick Unblock → OK. Without that it warns you every time you open it.

    Windows tags everything a browser downloads with where it came from, and a page opened from your own disk has no address it recognises — so it assumes the worst. Unblocking clears the tag. The helper never adds one.
